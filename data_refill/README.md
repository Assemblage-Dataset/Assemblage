Assemblage Linux Dataset
Please note, the Assemblage code is published under the MIT license, while the dataset specify each binary's source code repository license, please obey the original repository's license.

This reposotory holds the Linux public dataset for [Assemblage](https://assemblage-dataset.net/), and you can find the paper [here](https://arxiv.org/abs/2405.03991).

We also provide all the licensed source code (w/ all Git info) for these binaris available upon request, as the compressed file is too large (~1.5T after at highest compression level), please contact us and we can setup sftp or some netdisk for data transfer.
